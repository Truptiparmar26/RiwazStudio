# Riwaz Studio

Premium full-stack website for a professional photo editing studio.

## Stack

- React, Vite, Tailwind CSS
- Framer Motion, GSAP, Lenis, Three.js, React Three Fiber, Drei
- Node.js, Express, MongoDB, Mongoose
- JWT authentication and protected admin APIs

## Run Locally

```bash
npm install
npm run dev
```

Create `server/.env`:

```bash
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/riwaz-studio
JWT_SECRET=replace-this-with-a-long-secret
CLIENT_URL=http://localhost:5173
ADMIN_EMAIL=admin@riwazstudio.com
ADMIN_PASSWORD=change-this-password
```

Frontend: `http://localhost:5173`

Backend health: `http://localhost:5000/api/health`
